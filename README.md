# 🦇 Modo Wayne

Protocolo diário pessoal: Oração · Treino · Trabalho · Estudo. Missão: Empreender.

PWA sem dependências — abre offline, instala na tela inicial, dados salvos no aparelho.

## Publicar no GitHub Pages
1. Envie estes arquivos para um repositório.
2. Settings → Pages → Source: "Deploy from a branch" → branch `main`, pasta `/ (root)` → Save.
3. Em ~1 min o app fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
